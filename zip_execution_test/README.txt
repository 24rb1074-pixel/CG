3D Tetris
=========

1. 作品概要
-----------
Python、GLFW、PyOpenGL、NumPy、Pillowを使用した3Dテトリスです。
7種類のテトリミノ、ライン消去、スコア、レベル、NEXT、HOLD、
ゴースト、ハードドロップ、一時停止などを実装しています。


2. 動作環境
-----------
- Python 3.10以上
- OpenGLを利用できるWindows環境
- キーボード


3. 必要ライブラリのインストール
-------------------------------
コマンドプロンプトまたはPowerShellで、このREADME.txtと
requirements.txtがあるフォルダへ移動し、次を実行してください。

    python -m pip install -r requirements.txt


4. 実行方法
-----------
次のコマンドを実行してください。

    python tetris.py

数字テクスチャを読み込むため、tetris.pyとdigitsフォルダの位置関係を
変更しないでください。


5. 操作方法
-----------
Left / Right   : ミノを左右へ移動
Down           : ソフトドロップ
Space          : ハードドロップ
Up / E         : 右回転
Q / Left Ctrl  : 左回転
C / Left Shift : ホールド
Escape         : 一時停止／再開
R              : ゲームをリスタート
U              : ゲームを終了


6. 画面表示
-----------
- 画面左：HOLD中のミノ
- 画面中央：10×20マスのプレイフィールド
- 画面右：次に出現する5個のミノ
- 画面下部：数字テクスチャによるスコア
- ウィンドウタイトル：スコア、消去ライン数、レベル、ゲーム状態

8. 使用ライブラリ
-----------------
- glfw：ウィンドウ作成、入力、時間管理
- PyOpenGL：3D描画、照明、材質、テクスチャ、透過処理
- NumPy：座標、テトリミノ、フィールド配列の管理
- Pillow：数字画像の読み込みとOpenGL用データへの変換


9. 既知の仕様
-------------
- 回転補正は公式SRSを完全再現したものではなく、簡易ウォールキックです。
- T-spin、コンボ、Back-to-Back、効果音は実装対象外です。
